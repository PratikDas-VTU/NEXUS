# Frontend Breakdown

## Field App
1. App shell/PWA
2. Connectivity banner
3. Home screen
4. Report flow
5. Location capture UI
6. Priority selection
7. Incident confirmation
8. My incidents
9. Incident detail/status
10. Peer/relay status
11. Accessible error/loading states

## Dashboard
1. Dashboard shell
2. Top status bar
3. Alert panel
4. Incident queue
5. Filters
6. Incident detail
7. Map
8. Verify/assign/resolve controls
9. Relay/sync history
10. Governance/audit view

## Frontend principle

Build the Field App first. Dashboard comes after the core incident path and relay path are stable.
