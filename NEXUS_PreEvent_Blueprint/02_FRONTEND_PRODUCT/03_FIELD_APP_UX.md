# NEXUS Field App — UX Specification

## Design goal

A user may be frightened, moving, injured, distracted, or have poor connectivity. The interface must therefore reduce cognitive load.

## Visual direction
- Light theme.
- Clean white/light surfaces.
- Strong semantic priority indicators.
- Large buttons.
- Large readable labels.
- Minimal navigation.
- Avoid decorative complexity.
- Keep emergency actions visually dominant.
- Do not rely on color alone; pair color with text/icon.

## Home screen
Primary actions:
1. REPORT EMERGENCY
2. REPORT RESOURCE NEED
3. REPORT SAFETY ISSUE

Secondary:
- My reports
- Connection status
- Help/about

## Report flow
Step 1: What happened?
Step 2: How urgent?
Step 3: How many people?
Step 4: Where?
Step 5: Optional description/evidence
Step 6: Review and SEND

If offline:
- Replace misleading "Send to server" language with "Save & relay".
- Show "Saved on this device" immediately after persistence.
- Show relay/sync status separately.

## Panic-friendly rules
- One primary action per screen.
- Large touch targets.
- No mandatory long text.
- Defaults where safe.
- Confirmation after local save.
- Never hide an emergency report behind connectivity.
- Never say "failed to send" when the report was safely stored locally.
